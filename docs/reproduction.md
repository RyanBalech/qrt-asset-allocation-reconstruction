# Reproduction boundary

This repository preserves the research implementation and its frozen v5 parameters. A fresh clone cannot reproduce the submission from challenge CSVs alone: earlier experiment stages generated large arrays, stock-price panels, calendar mappings and an out-of-fold CatBoost prior. They are excluded from Git because they are large, depend on challenge data, or are third-party market-data caches.

The scripts expect those files beside the Python files in `research/`, where `overlap_model.ROOT` points. The main dependencies used for the original run were Python 3.13.5, NumPy 2.3.2, pandas 2.3.1, SciPy 1.16.2, CatBoost 1.2.8 and exchange-calendars 4.13.2. `requirements.txt` also lists the parquet and other imported packages. Results may change with later market-data corrections or dependency versions.

Important intermediate inputs include:

- `data.parquet`, `panel.npz`, `training_order.csv`, and `baseline_predictions.npz` from data preparation and the initial model;
- `v4_training_calendar.csv`, `v4_test_calendar_stock.csv` or `v4_test_calendar.csv`, and `v4_calendar_final_test.csv` from date recovery;
- `v4_stock_prices_expanded_g*.parquet`, `v5_stock_prices_g1.parquet`, `v5_stock_prices_g2.parquet`, and `v5_stock_prices_g4.parquet` from the public-market cache;
- `v5_pool_manifest.json`, generated by `v5_meta_features.py`, plus the feature pools and model checkpoints generated by the training scripts.

Once those local intermediates exist, the intended order is:

```powershell
python research/v5_meta_features.py
python research/v5_broad_meta_features.py
python research/v5_adaptive_meta_features.py
python research/v5_train_adaptive.py
python research/v5_pipeline.py
$env:QRT_TEST_CSV = 'C:\path\to\X_test.csv'
python research/v5_finalize.py
```

The final script checks the row order and features against the original test CSV and writes `research/submission_improved_v5.csv`. Its hash should be compared with the value in [evaluation notes](evaluation.md). Running the training and date-alignment stages requires substantial memory and cached public data. The exclusion of those artifacts is intentional; the command sequence is a guide for holders of the original research workspace, not a promise of fresh-clone reproducibility.
